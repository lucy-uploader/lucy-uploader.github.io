Lucy Uploader - Privacy Policy

Effective date: November 3, 2026

Lucy Uploader is a personal software tool operated by its owner to upload the owner's own videos to the owner's own TikTok account (@lucy.net7) through TikTok's official Content Posting API.

What data the tool handles: TikTok OAuth access and refresh tokens for the authorized account, used only to call TikTok's official API on the owner's behalf; basic profile information returned by TikTok (such as the account open ID and display name) to confirm the correct account is connected; the video files and captions the owner chooses to upload.

How the data is used: solely to upload and publish the owner's own content to the owner's own TikTok account. It is not sold, rented, or shared with third parties, and it is not used for advertising or profiling.

Storage and security: OAuth tokens are stored in a protected credential file accessible only to the tool. The owner can revoke the tool's access at any time from the TikTok app or by deleting the stored tokens.

Third parties: the tool communicates only with TikTok's official API (open.tiktokapis.com). TikTok's own privacy policy governs data once it is on TikTok's platform.
